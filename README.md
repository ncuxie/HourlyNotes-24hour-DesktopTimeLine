# HourlyNotes-24hour-DesktopTimeLine

一款极简WPF桌面备忘录，24小时时间轴按小时记录待办，单文件exe免安装运行。
[![MIT License](https://img.shields.io/badge/license-MIT-green?flat-square)](LICENSE)

<img width="270" height="345" alt="24小时时间轴界面" src="https://github.com/user-attachments/assets/76fa63d3-b9cc-4da8-952f-a6088148e0a7" />


## ✨ 功能

- 24小时横向时间轴，分时段记录日程、待办
- 纯WPF原生，无冗余第三方依赖
- 自包含单文件，发给他人直接打开，不用装.NET
- 同时支持 win-x64 / win-arm64 Windows设备

## 🪟 运行要求

Windows 10 / 11（x64、ARM64通用）

## 📦 普通用户使用

前往 [Releases](https://github.com/ncuxie/HourlyNotes-24hour-DesktopTimeLine/releases) 下载对应架构 `HourlyNotes.exe`，双击即用。


## ❓ 常见问题

1. **杀毒误报**：单文件自包含打包特征，源码开源可自行编译
2. **ARM设备卡顿**：打包时指定 `-Runtime win-arm64` 生成原生包
3. **ps1无法执行**：管理员权限放开脚本，用完恢复限制策略
